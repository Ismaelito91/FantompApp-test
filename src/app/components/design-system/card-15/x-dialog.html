Comment remplir le formulaire ? - X

Voici ce qu’il faut faire pour remplir le formulaire ci-dessous:
1. Sélectionner “Je souhaite poser une question” dans “Comment pouvons-nous vous aider ?”
2. Sélectionner “De la suppression de données” dans “Veuillez nous en dire plus”
3. Copier/coller le modèle ci-dessous dans “Veuillez saisir votre question” et le remplacer avec ce qui nous concerne.
