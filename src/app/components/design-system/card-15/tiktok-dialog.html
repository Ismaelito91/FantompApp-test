Comment remplir le formulaire ? - TikTok

Voici ce qu’il faut faire pour remplir le formulaire ci-dessous:
1. Fais des captures d’écran
2. Sélectionner le pays où on habite
3. Écrire son nom d’utilisateur TikTok
4. Sélectionner “Mes données TikTok” dans “Quelle est ta demande ou préoccupation ?”
5. Sélectionner “J’ai une question sur l’exercice de mes droits” dans “Sélectionne une sous-catégorie”
6. Copier/coller le modèle ci-dessous dans “Décris ta demande” et le remplacer avec ce qui nous concerne.
